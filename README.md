# FUNNY_CODE

Коллекция приложений, сгенерированных нейросетями.

## Проекты

### [AI Broom MP3](AI_Broom_MP3/)

![AI Broom MP3](AI_Broom_MP3/BroomMP3_Preview.png)

Приложение для анализа и очистки MP3-файлов от AI-отпечатков (водяных знаков).

**Возможности:** Drag & Drop, анализ аудио с FFT/STFT, визуализация, очистка AI-отпечатков.

---

### [GenQRLite](GenQRLite/)

![GenQRLite](GenQRLite/MinimalDotNetApp_Preview.png)

Генератор QR-кодов с минимальным интерфейсом.

**Возможности:** Генерация QR-кодов из текста, сохранение в файл.

---

### [MinimalDotNetApp](MinimalDotNetApp/)

![MinimalDotNetApp](MinimalDotNetApp/MinimalDotNetApp_Preview.png)

Минимальное Windows-приложение на .NET 8 с Native AOT (~970 КБ).

**Возможности:** Изменение размера окна, кнопка закрытия, перетаскивание за тело окна.

---

### [RandomRenamer](RandomRenamer/)

![RandomRenamer](RandomRenamer/RandomRenamer_Preview.png)

Windows Forms приложение для случайного переименования MP3-файлов.

**Возможности:** Drag & Drop, случайное переименование, редактирование метаданных, настраиваемый список имён.

---

### [SmileText](SmileText/)

![SmileText](SmileText/SmileText_Preview.png)

Приложение для преобразования русского текста в эмодзи-смайлы и обратно.

**Возможности:** Текст в смайлы и обратно, редактор смайлов, случайный выбор.

---

### [SystemMonitor](SystemMonitor/)

![SystemMonitor](SystemMonitor/SystemMonitor_Preview.png)

WPF-приложение для мониторинга системных ресурсов в реальном времени.

**Возможности:** Мониторинг CPU, памяти, сети, GPU и GPU-памяти с графиками истории.

---

### [TGHistoryRipper](TGHistoryRipper/)

![TGHistoryRipper](TGHistoryRipper/TGHistoryRipper_Preview.png)

WPF-приложение для извлечения и категоризации ссылок из экспорта истории чатов Telegram.

**Возможности:** Drag & Drop JSON, удаление полей, извлечение ссылок, экспорт по хештегам в Markdown.

---

### [UnrealHelperBatFiles](UnrealHelperBatFiles/)

Набор вспомогательных batch-файлов для работы с Unreal Engine проектами.

**Файлы:** `__BUILD.bat`, `__DEL_BINARIES.bat`, `__GEN_PROJECT_FILES.bat`, `__Pack_Code_To_Text.bat`

---

### [YTVtoText](YTVtoText/)

![YTVtoText](YTVtoText/YTVtoText_Preview.png)

Приложение для скачивания видео с YouTube и распознавания текста из аудио через Vosk.

**Возможности:** Скачивание видео, распознавание речи, скачивание субтитров, сохранение в TXT.

---

## Требования

- Windows 10/11
- .NET 8.0+ (для большинства проектов)
- .NET 10.0 (для SystemMonitor)

## Лицензия

Все проекты распространяются под лицензией MIT. Приложения сгенерированы нейросетями.
