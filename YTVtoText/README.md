Приложение для скачивания видео с YouTube и распознавания текста из аудио дорожки с помощью нейросети Vosk.

## Возможности

### Основные функции

- 📥 **Скачивание видео с YouTube** в минимальном качестве для быстрой обработки
- 🎬 **Скачивание видео в HQ** — максимальное качество
- 🎤 **Распознавание речи** с помощью нейросети Vosk
- 📄 **Скачивание субтитров** (если доступны)
- 💾 **Сохранение текста** в TXT файл
- ⚙️ **Автоматическая загрузка зависимостей** (модель Vosk, библиотеки, ffmpeg, yt-dlp)

### Настройки

- ✅ **Сохранить видео** — оставить видео файл после обработки
- ✅ **Скачать субтитры** — загрузить субтитры с YouTube (если доступны)
- ✅ **Распознать текст** — выполнить распознавание речи через Vosk
- 🎯 **Выбор модели Vosk**:
  - Small Russian (ru) — компактная модель для русского языка
  - Small English (en) — компактная модель для английского языка
  - Medium Russian (ru) — улучшенная модель для русского языка

## Использование

### Обычное скачивание и распознавание

1. Запустите приложение `YTVtoText.exe`
2. Вставьте ссылку на YouTube видео в поле ввода
3. Настройте параметры (по желанию)
4. Нажмите кнопку "Скачать"
5. Дождитесь завершения процесса

### Скачивание в HQ (максимальное качество)

1. Вставьте ссылку на YouTube видео
2. Нажмите кнопку "Скачать видео в HQ"
3. Дождитесь завершения

## Процесс обработки

При первом запуске приложение автоматически загрузит:
- 📦 Модель Vosk (~50 МБ для small, ~1.8 ГБ для medium)
- 📦 Библиотеку Vosk (~26 МБ)
- 📦 ffmpeg (~100 МБ)
- 📦 yt-dlp (~18 МБ)

Этапы обработки видео:
1. ⬇️ Скачивание видео с YouTube
2. 📄 Скачивание субтитров (если включено)
3. 🎵 Декодирование аудио из видео (разбивка на чанки по 29 секунд)
4. 🤖 Распознавание текста через Vosk (если включено)
5. 💾 Сохранение результата в TXT файл

## Структура файлов

После работы приложения:
```
YTVtoText.exe                          - Основной исполняемый файл
YTVtoText.ico                          - Иконка приложения
vosk-model-small-ru-0.22/              - Модель Vosk (русский язык)
vosk.dll, libvosk.dll                  - Библиотеки Vosk
ffmpeg.exe                             - Конвертер аудио/видео
yt-dlp.exe                             - Загрузчик видео с YouTube
{название_видео}_text.txt              - Распознанный текст
{название_видео}_subtitles.txt         - Субтитры (если скачаны)
{название_видео}_HQ.mp4                - Видео в HQ качестве
```

## Сборка проекта

```bash
dotnet build -c Release
```

Публикация в папку `publish`:
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishDir=publish
```

Или используйте готовый скрипт:
```bash
build.bat
```

## Технологии

- .NET 8.0 + WPF
- Vosk API для распознавания речи
- FFmpeg для обработки видео
- yt-dlp для загрузки с YouTube
- C#

## Примечания

- При первом запуске загрузка зависимостей может занять несколько минут
- Распознавание текста зависит от выбранной модели Vosk
- Видео после обработки удаляется автоматически (если не включена опция "Сохранить видео")
- Временные файлы (чанки аудио) удаляются после обработки
- HQ видео сохраняется с суффиксом "_HQ" в названии файла
- Названия файлов автоматически очищаются от недопустимых символов
