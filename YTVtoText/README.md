Приложение для скачивания видео с YouTube, распознавания текста из аудио дорожки и автоматической конвертации видео.

## Возможности

### Основные функции

- 📥 **Скачивание видео с YouTube** в минимальном качестве
- 🎬 **Скачивание видео в HQ** — максимальное качество с автоматической конвертацией
- 📁 **Поддержка плейлистов** — скачивание всех видео из плейлиста
- 🎤 **Распознавание речи** с помощью нейросети Vosk
- 📄 **Скачивание субтитров** (если доступны)
- 💾 **Сохранение текста** в TXT файл
- 🔄 **Автоматическая конвертация** в H.264 + AVI для совместимости с Media Player Classic
- ⚙️ **Автоматическая загрузка зависимостей** (модель Vosk, библиотеки, ffmpeg, yt-dlp)

### Настройки

- ✅ **Сохранить видео** — оставить видео файл после обработки
- ✅ **Скачать субтитры** — загрузить субтитры с YouTube (если доступны)
- ✅ **Распознать текст** — выполнить распознавание речи через Vosk
- ✅ **High-Quality Video** — включить скачивание в HQ с конвертацией
- 🎯 **Выбор модели Vosk**:
  - Small Russian (ru) — компактная модель для русского языка
  - Small English (en) — компактная модель для английского языка
  - Medium Russian (ru) — улучшенная модель для русского языка

## Использование

### Обычное скачивание

1. Запустите приложение `YTVtoText.exe`
2. Вставьте ссылку на YouTube видео (или плейлист)
3. Настройте параметры (по желанию)
4. Нажмите кнопку "Скачать"
5. Дождитесь завершения процесса

### Скачивание в HQ (максимальное качество)

1. Включите чекбокс "High-Quality Video"
2. Вставьте ссылку на YouTube видео
3. Нажмите кнопку "Скачать в HQ"
4. Дождитесь завершения

### Скачивание плейлиста

1. Вставьте ссылку на плейлист YouTube
2. Нажмите кнопку "Скачать"
3. Приложение автоматически определит все видео в плейлисте
4. Все видео будут обработаны последовательно

## Процесс обработки

### Обычный режим

1. ⬇️ Скачивание видео с YouTube
2. 📄 Скачивание субтитров (если включено)
3. 🎵 Декодирование аудио из видео (разбивка на чанки по 29 секунд)
4. 🤖 Распознавание текста через Vosk (если включено)
5. 💾 Сохранение результата в TXT файл

### Режим HQ

1. ⬇️ Скачивание видео в максимальном качестве
2. 🔄 Определение кодека видео
3. 🔀 Склейка видео и аудио (если скачаны отдельно)
4. ⚡ Конвертация в H.264 (если нужно)
5. 📦 Сохранение в формате AVI

**Примечание:** Видео в формате H.264 не конвертируются повторно — они просто копируются.

## Структура файлов

После работы приложения в папке сохранения:
```
d:\youtube_download\
├── {название_видео}_HQ_converted.avi     - Конвертированное видео
├── {название_видео}_subtitles.txt         - Субтитры (если скачаны)
└── {название_видео}_text.txt             - Распознанный текст
```

В папке с приложением:
```
YTVtoText.exe                              - Основной исполняемый файл
ffmpeg.exe                                 - Конвертер аудио/видео
yt-dlp.exe                                - Загрузчик видео с YouTube
vosk-model-*/                             - Модель Vosk
vosk.dll, libvosk.dll                      - Библиотеки Vosk
```

## Сборка проекта

```bash
dotnet build -c Release
```

Публикация:
```bash
dotnet publish -c Release -r win-x64 --self-contained true
```

## Технологии

- .NET 8.0 + WPF
- Vosk API для распознавания речи
- FFmpeg для обработки и конвертации видео
- yt-dlp для загрузки с YouTube
- C#

## Примечания

- При первом запуске загрузка зависимостей может занять несколько минут
- Распознавание текста зависит от выбранной модели Vosk
- Видео после обработки удаляется автоматически (если не включена опция "Сохранить видео")
- Временные файлы (чанки аудио) удаляются после обработки
- HQ видео автоматически конвертируется в AVI с кодеком MPEG-4 для совместимости с Media Player Classic
- Названия файлов автоматически очищаются от недопустимых символов
- Интерфейс блокируется во время обработки для предотвращения конфликтов
