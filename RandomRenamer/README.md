# MP3 Random Renamer

![RandomRenamer](RandomRenamer_Preview.png)

![Windows](https://img.shields.io/badge/Windows-10%2F11-blue?logo=windows)
![.NET](https://img.shields.io/badge/.NET-8.0-512BD4?logo=dotnet)

WPF-приложение для случайного переименования MP3-файлов с возможностью редактирования метаданных.

## Возможности

- **Drag & Drop** — перетаскивайте MP3-файлы прямо в окно приложения
- **Случайное переименование** — файлы получают случайные имена из вашего списка
- **Редактирование метаданных** — изменение автора и названия в тегах MP3
- **Настраиваемый список имён** — добавляйте, удаляйте и редактируйте имена для переименования
- **Логирование** — отслеживайте все выполненные операции

## Технологии

- .NET 8 (WPF)
- TagLibSharp — для работы с метаданными MP3-файлов

## Сборка

Два способа:

1. Запустить `build.bat`
2. Вручную:
```bash
dotnet publish MP3RandomRenamer.csproj -c Release -o publish
```

## Использование

1. Запустите `MP3RandomRenamer.exe` из папки `publish/`
2. Перетащите MP3-файлы в область перетаскивания
3. Укажите автора (по умолчанию "NGB")
4. Выберите или отредактируйте список имён
5. Нажмите кнопку переименования

При первом запуске файл `names.txt` будет создан в папке с приложением. Вы можете редактировать его вручную или через встроенный редактор.

## Структура проекта

- `MainWindow.xaml` — главное окно с дизайном
- `names.txt` — список прилагательных для случайного выбора
- `build.bat` — скрипт для сборки
